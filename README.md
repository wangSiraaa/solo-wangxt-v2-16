# 小册子拼版工具（骑马订）

纯浏览器运行的骑马订拼版工具，面向小型印刷工作室：导入 PDF 后即可检查页序、双面翻转方向与补白位置，并导出可直接上机的拼版 PDF。**无服务端**，所有数据留在本地浏览器。

## 功能对照

| 需求 | 实现 |
| --- | --- |
| Vue 3 + TypeScript | Vite 工程，Pinia 管理状态 |
| PDF.js 渲染原页 | `src/pdf/preview.ts`，仅生成屏幕用低分辨率位图 |
| pdf-lib 生成拼版文件 | `src/pdf/exporter.ts`，`embedPdf` **矢量嵌入**原页，预览位图绝不进入最终 PDF |
| 工程参数保存在 IndexedDB | `src/db/idb.ts`，设置、排除页与 PDF 字节自动防抖保存，刷新后恢复 |
| 补白位置明确展示 | 页数非 4 的倍数时自动补白，纸张视图中以灰底虚线框标注"补白"，导出前检查列出补白所在的逻辑页码 |
| 封面单独计纸 | 可选：封面/封二/封三/封底独立一张纸（可设不同纸张规格），正文页数单独补齐 |
| 长边/短边翻转 | 长边翻转背面正立；短边翻转背面整体旋转 180°，预览与导出一致 |
| 改变纸张规格后重新检查 | 纸张/出血任一变更即时重算拼版并重跑出血、裁切检查 |
| 原页→纸张正反面对应视图 | 每张纸的正反两面各一幅预览，标注左右槽页码（左 P8 / 右 P1 …） |
| 排除指定页 | 原页列表点击排除/恢复，拼版即时重算 |
| 撤销调整 | 所有设置与排除操作入撤销栈（上限 50 步） |
| 导出前检查 | 页数、补白、出血/裁切溢出、输出质量说明；存在错误时禁止导出 |
| 八页/十一页样册 | 一键载入内置样册（A5，带页码与 TOP 方向标记），便于核对下载文件的页序、补白与旋转 |

## 拼版规则

- 标准骑马订 2-up：第 i 张纸正面 `[P-2i, 2i+1]`，背面 `[2i+2, P-2i-1]`（P 为补齐后的总页数）。
- 补白一律位于成书末尾（逻辑最后几页）。
- 纸张横放，页槽 = 纸宽一半 × 纸高；原页 1:1 居中放置，不缩放。
- 导出 PDF 含折线（虚线）与页槽裁切框，纸张顺序为 正面/背面 交替，直接双面打印即可。

## 开发

```bash
npm install
npm run dev        # 开发服务器
npm test           # 单元/集成测试（16 个用例：页序、补白、翻转、导出尺寸与旋转矩阵等）
npm run build      # 类型检查 + 构建到 dist/
```

`e2e/smoke.mjs` 为可选的浏览器端到端冒烟（需要能运行 Chromium 的桌面环境）：

```bash
npm run build && npx vite preview --port 4173 &
node e2e/smoke.mjs
```

## 目录

```
src/
  imposition/impose.ts   拼版核心（纯函数，页序/补白/封面分纸/翻转标记）
  pdf/preview.ts         PDF.js 打开与低分辨率渲染
  pdf/exporter.ts        pdf-lib 矢量导出（含短边翻转 180° 旋转）
  pdf/preflight.ts       导出前检查（出血/裁切/补白/质量）
  pdf/sample.ts          8 页 / 11 页样册生成
  store/project.ts       Pinia 状态、撤销栈、IndexedDB 自动保存
  db/idb.ts              IndexedDB 封装
  components/            导入、设置、原页列表、纸张正反面视图、导出面板
```
