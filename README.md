# 骑马订小册子拼版工具（纯浏览器）

小型印刷工作室用的骑马订（saddle-stitch）2-up 拼版工具。工作人员导入 PDF 后，可在浏览器内
检查骑马订页序、长/短边双面翻转后的背面方向、补白位置、出血与裁切范围，排除指定页并撤销，
最后通过导出前检查，下载由**原始 PDF 矢量重新拼版**的成品文件。

- 框架：Vue 3 + TypeScript + Vite
- 原页渲染：PDF.js（**仅用于低分辨率屏幕预览**）
- 最终拼版：pdf-lib（从原始字节重新嵌入矢量页面，**绝不使用预览位图**）
- 参数持久化：IndexedDB（无服务端数据库，文件不出本机）

## 快速开始

```bash
npm install
npm run dev          # 本地开发
npm run build        # 类型检查 + 生产构建到 dist/
npm run preview      # 预览构建产物
```

打开后可一键载入内置 **8 页** 或 **11 页** 样册（每页带大页码、顶部色条和方向箭头），
无需自备 PDF 即可核对页序、补白与旋转。

## 功能对照

| 需求 | 实现 |
| --- | --- |
| 骑马订页序检查 | “纸张正反面”与“翻页顺序”两个视图；页序在 `src/lib/imposition.ts` 单一来源 |
| 双面翻转效果 | 短边翻转背面不旋转；长边翻转背面整体 180°，预览背面方向明显不同 |
| 页数不足 4 的倍数 | 自动补齐并**明确展示补白位置**（横幅 + 纸张格 + 原页条占位） |
| 封面单独计纸 | 封面帖（最外帖）标记并在设置中单独计纸，内页另计 |
| 改纸张重新检查出血/裁切 | `checkGeometry()` 对出血、安全区、爬移、裁切边距实时告警/报错 |
| 原页→纸张正反面对应 | 每张纸渲染正面/背面，格内标注「纸左/纸右 · 面板 · 位置 · 原页 · 旋转」 |
| 排除指定页 | 点击缩略图排除/恢复；排除位保留并画 EXCLUDED 标记 |
| 撤销调整 | 排除操作有独立撤销/重做栈（`src/lib/history.ts`） |
| 导出前检查 | `src/lib/preflight.ts`，必须显式确认“预览≠最终稿”，有 error 时禁用下载 |
| 预览不当最终稿 | 渲染与导出严格分离；导出只认导入时的原始 `Uint8Array` |
| 8 页 / 11 页样册 | 内置生成；下载文件的页序、补白、旋转经自动化断言与预览一致 |

## 拼版规则（已用数值折叠验证）

输出为横向大纸（成品页宽 × 2）。最外帖 `k=0`，面板到逻辑页（1 起）：

```
正面 A：  [ N-2k | 1+2k ]
背面 B：  [ N-1-2k | 2+2k ]   ← 面板名配对；打印翻纸后物理左右镜像
```

- **短边翻转**（绕竖直短边）：四个面板旋转角均为 0°。
- **长边翻转**（绕水平长边）：背面 LB/RB 旋转 180°。
- 任何双面翻转都会让**背面物理半张左右镜像**：背面左页（偶页码）落在纸的左半张、
  右页（奇页码）落在纸的右半张。导出与预览共用 `physicalHalf()`，不会各写一套。

推导与暴力求解过程见 `docs/verification/fold-proof.mjs`。

## 测试与验证

```bash
npm test             # 单元测试：补白/页序/阅读顺序/旋转/物理半张/排除
npm run test:e2e     # 生成 8/11 页样册 → 真实导出 → pdf.js 解析断言（143 项）
npm run test:geo     # 逐面板四角几何：物理半张 + 朝向（长/短边 × 8/11 页）
npm run test:browser # Playwright 真机冒烟（需要可运行的 Chromium 及其系统库）
```

`test:e2e` 会把拼版样例写到 `test-output/`（git 忽略），可人工打印折叠复核。
验证项包括：输出页数 = 纸张数 × 2、展开尺寸、每面源页数量、补白位无源页内容、
长边背面含 180° 嵌入矩阵而短边不含、每面板物理半张与朝向。

```
src/components/        SheetView / ReadingView / PageManager / SettingsPanel / ExportPanel

```
